# Smart Card Admin — تطبيق الأدمن فقط (Dart / Flutter)

تطبيق أندرويد مخصص بالكامل **للأدمن فقط** (بدون أي واجهة أو تدفق للعملاء) لإدارة منصة Smart Card والتحكم المباشر في رموز QR على قاعدة بيانات Cloud Firestore السحابية.

## المميزات الحصرية للأدمن
- تسجيل دخول مشفّر بـ SHA-256 متزامن مع إعدادات المنصة السحابية (`settings/auth`).
- عرض إحصائيات فورية بأنيميشن ثلاثي الأبعاد (إجمالي الأكواد، المفعّلة، المسحات).
- مسح رموز QR بالكاميرا (مع طلب إذن الكاميرا وزر إعادة التفعيل) أو من المعرض للتعديل الفوري.
- توليد أكواد QR جديدة مجمعة مع تحديد مدة الصلاحية الافتراضية.
- ربط البطاقات بجميع المنصات (واتساب، إنستاباي، محافظ كاش 1-4 بتعرف تلقائي للشبكة، حساب بنكي، تيك توك، إنستغرام، فيسبوك، تيليجرام، سناب شات، اتصال، موقع ويب).
- حذف الروابط القديمة نهائياً من قاعدة البيانات عبر زر **حذف من قاعدة البيانات** قبل الحفظ.
- تجديد الاشتراكات (+1، +3، +12 شهر أو تفعيل دائم) وتصفير عداد المسحات ومشاركة صورة QR.

## بناء ملف التثبيت (APK)
```bash
chmod +x build_apk.sh
./build_apk.sh
```
يتم إخراج ملف التثبيت الجاهز مباشرة في: `public/downloads/SmartCard-Admin.apk`.
